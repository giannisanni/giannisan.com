# giannisan.com

Personal site of Gianni Sanrochman. Static page, no build step, deployed with GitHub Pages.

The statues are rendered client-side as halftone tiles on a canvas; tiles disperse away from the
cursor and spring back. `nike.png` and `thinker.png` are downscaled derivatives of the photos below
and carry the same licenses.
